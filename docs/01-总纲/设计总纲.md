> **本文管什么**：设计意图 —— 这游戏靠什么好玩、产品定位裁决、抄三11 的哪几条、不抄哪几条、什么坚决不做。
> **本文不管什么**：具体数字（查 [项目基线](../00-基线/项目基线.md)）、具体规则（查 [规则底座](规则底座.md)）、

## 1. 一句话（2026-11-04 裁决 · C 修订版）

**一款以《三国志 11》的战略与战术结构为骨架、以自创内政循环为核心的回合制策略 Web 游戏。**

> **裁决记录**：2026-11-04，北洛。在「A 回到《三国霸业》复刻 / B 真对标三11 / C 承认是自己的游戏」中选定 C，
> 并追加「引入特技体系、战法气力、技巧研发、委任军团、水路、全地图不切战斗小地图」六项要求。
> 因此是 **C 修订版：内政核自创 + 战术/战略层三11 化**。
> 它不是纯 C（纯 C 不补三11 机制），也不是 B（B 要拆掉自创内政层）。**不要再把本作简称「仿三11」或「复刻版」。**

分三层说清，避免「仿三11」被当成全面复刻、或「玩法是自己的」被当成拒绝三11 机制：

| 层 | 归属 | 内容 |
| --- | --- | --- |
| **内核（自创，保留）** | 本作 | 营造工程、国策三选一、政令 / 朝议、一战一题、一局三幕、月报归因 |
| **战略与战术骨架（引入三11）** | 三11 结构 | 全地图不切战场、武将特技体系、战法与气力、技巧研发、委任军团、水路航行 |
| **沿用三11 的数据与观感** | 三11 | 五维武将、一队三将、旬为节拍、关港据点、版图铺色与墨迹边界 |

**3×3 城郭 + 四门是本作自创的攻城形态**（借三11 城郭的观感，不是三11 规则），
**国策三选一是现代重制自创**（不是三11 机制）。两者此前在旧 §5 被误标为「三11 的机制」，本次改正，见 [玩法基准矩阵](玩法基准矩阵.md) #18 / #19。

**判据**：任何新提案先问它属于哪一层。内核层不许用「三11 同制」背书；
战略/战术层不许用「本作特色」拒绝三11 的既有解。

## 2. 核心循环

游戏有三层节拍，玩家在三个尺度上做决定：

| 尺度 | 玩家在做什么 | 关键约束 |
| --- | --- | --- |
| **月** | 朝议 → 分配政令 → 决定这个月先解决什么 | 每城政令 = 2 + 在城武将/3，上限 4；月度点击目标 ≤ 20 |
| **旬**（1 月 = 3 旬） | 行军 → 围城 → 攻城，逐旬下令 | 每支部队每旬 1 个动作（移动不占动作）；每将每月只能行军一次 |
| **季**（3/6/9/12 月） | 税收入账，看这一季的家底 | 税率 1.2；金钱上限 30000，粮食无单城上限 |
| **局** | 立足 → 争锋 → 定鼎，三幕推进 | 幕有退出条件，不是「占够 40% 城」 |

**为什么是「旬」不是「月」**：月回合 + 59 城 + 合理行军速度，三者不能同时成立。
这是《全地图模式升级评估》里点名的**硬约束** —— 是设计问题，不是实现问题。
选「旬」是唯一能同时满足三者的组合，代价是玩家每月要下 3 次令而不是 1 次。

**委任军团为什么必须做**：59 城 / 338 将 / 一旬一令，中期每旬点击约 40–60 次，三11 同期 5–10 次。
差距不是数值，是缺减负骨架。C 修订版把「委任军团」列为引入项，正是对冲全地图带来的操作量。

## 3. 三条设计主线

所有设计取舍都可以回到这三条上。它们来自 GDD 优化规划报告（基线 rev.5）。

| 主线 | 目标 | 判据（可以拿来否决一个提案） |
| --- | --- | --- |
| **A · 数值：切断套利，重建取舍** | 农业管「数量」、商业管「质量」 | 任何单一加点路线不超过最优产能的 120% |
| **B · 信息：行动前可预览，结算后可归因** | 月报、上限预警、伤害区间、计策成功率全部前置 | 月度操作点击 ≤ 40（v2 目标 ≤ 20） |
| **C · 工程：确定性优先，内容后置** | 命令 → 纯函数 → 新状态；随机数按系统分流 | 读档 100% 复现 |

**主线 C 是最容易被违反的一条**。任何「先加个随机效果，以后再补确定性」的提案，都会在存档迁移和回归测试上付出十倍代价 —— 项目已经为这个教训付过一次账（`SAVE_VERSION` 从 5 到 6 清库）。

## 4. 四条体验支柱

主线管「怎么做得对」，支柱管「怎么做得**好玩**」。
它们的共同判断是：**系统已经够多了，问题是玩家不知道这个月先听谁的。**

| 支柱 | 要解决的问题 | 判据 |
| --- | --- | --- |
| **一屏一月** | 月度入口是城池列表，不是议程 | 2 城 5 令只需 2 次操作；经典模式 0 泄漏 |
| **一战一题** | 每场战斗的目标都是「把对面打完」 | 现代模式战斗 100% 有主目标；预览 / HUD / 战报三处一致 |
| **一局三幕** | 章节只是三个数字目标，不是叙事单元 | 幕有转折，后期清城量 −50% |
| **一眼一等** | 金色、红色、青色都在抢注意力 | 任何新面板先回答「它属于 T1/T2/T3/T4 哪一层」 |

**这四条不是功能清单，是验收口径**。一个「加了新系统」的版本如果四条支柱一条都没改善，那它就是负功。

## 5. 三11 机制的取舍（唯一入口：玩法基准矩阵）

> **2026-11-04 改写**。旧版这一节叫「抄三11 的什么，不抄什么」，它把两项自创机制标成三11 玩法、
> 又把三11 骨架拆散到四份文档里，是文档冲突的根源（见 [讨论稿](../../玩法基准梳理-讨论稿-2026-11-04.md) §2）。
> **本节不再维护逐条对照**，一律以 [玩法基准矩阵](玩法基准矩阵.md) 为准；矩阵是这一主题的唯一真值源。

### 5.1 C 修订版引入的六项（已裁决，进入排期）

| # | 引入项 | 裁决 | 边界 |
| --- | --- | --- | --- |
| 1 | **全地图玩法，不切战斗小地图** | 全面采纳 | 删除 `DEPLOY` / `createBattle` / `BattleScreen` / `BattleCanvas` / `GamePhase 'battle'`；规格见 [战斗卷](../02-系统/战斗.md) 篇一 §0 裁决 2 |
| 2 | **武将特技体系** | 采纳 | 从 12 条被动乘数升级为可学习 / 组合 / 战法联动的体系；不是加数字 |
| 3 | **战法与气力** | 采纳 | 战法消耗气力、与兵种适性联动；现有气力只是伤害乘数 + 溃散概率 |
| 4 | **技巧研发** | 采纳 | 势力级长期成长线；当前全库 0 命中，纯新增 |
| 5 | **委任军团** | 采纳 | 从城级 `AUTO_GOVERN` 升级为军团 / 都督，覆盖内政 + 征兵 + 运输 |
| 6 | **水路航行** | 采纳 | 水军走水面、可载陆军、`marchCost` 按兵种分流 |
| — | 水路 ≠ 独立水战 | **不做** | 不做舰船兵种单列、不做独立水战规则与界面；水路只是通行性与机动，与「不切小地图」一致 |

### 5.2 明确不做（不再讨论）

| 项 | 理由 |
| --- | --- |
| 内政设施自由摆放 + 邻接加成（市场 / 农田 / 造币 / 谷仓） | **这是本作与三11 最大的玩法分叉，不只是「UI 复杂」**。本作用营造工程（每城 2 位、4 类、2–3 月自动推进）替代，保住「一屏一月」的决策密度 |
| 单挑 / 舌战 | 独立小游戏，与主循环耦合弱；做了也只是一个可跳过的动画 |
| 结婚 / 义兄弟 / 人际关系网 | 需要长期关系建模，与「一局 3 幕」的节奏冲突 |
| 独立阵型系统 | 战法体系内的队形表现另议，不做独立阵型扩展 |
| 写实 3D / HD-2D 表现 | 程序化地图 + 高可读性是本作的成本优势，换表现等于换项目 |

### 5.3 旧否决的撤销记录

以下三条在旧版 §5 / §6 / 路线图 §14 里被写成「已裁决不再议」或「非目标」，
**2026-11-04 裁决已推翻**，以本节为准：

| 旧表述 | 出处 | 新状态 |
| --- | --- | --- |
| 「舰船兵种 + 独立水战规则：只做江面地形与补给影响，不做舰船。**已裁决，不再议**」 | 旧 §5 | 水路航行**纳入**；独立水战规则仍不做（见 5.1 边界） |
| 「不建议动，属设计分叉」：大地图无缝战斗 | [数值口径](../03-数据/数值口径.md) §3 P3 | **推翻**，全地图合一成为 C 修订版第 1 项 |
| 路线图 §12 待裁决 C「水战是否独立规则」 | [路线图](../04-计划/路线图.md) §12 | **已裁决**：引入水路通行，不做独立水战 |

### 5.4 最危险的诱惑（保留，但结论已更新）

> **全地图会稀释现有优势。**
>
> 本作现在的决策密度在「城内政令 + 一战一题 + 月报归因」。
> 全地图模式的决策密度会转移到「部队调度与补给」。
> 后者做不好，游戏会退化成**走路模拟器** —— 这是绝大多数三国志 11 仿制品的死因。

这条判断写在《全地图模式升级评估 v1》里，当时用来劝退「L 档（地图即战场 + 设施 + 迷雾）」。
**2026-11-04 裁决选择走 L 档形态（全地图合一），因此「要不要全地图」这个问题已关闭。**
但警告本身没有过期，只是换了问法：**委任军团与情报前置必须与全地图同批交付**，
否则 59 城 / 一旬一令会把玩家埋在重复劳动里。每次想加「地图上的新操作」时，先问一句：
这是在加决策，还是在加走路？

## 6. 非目标

以下事项**不在本轮范围内**，提出来会被直接否决（除非先改这份文档）：

- 多人联机、账号系统、在线排行
- 写实 3D / HD-2D；地图保持程序化与高可读性
- 地图随机生成、天气系统扩展、独立阵型系统扩展
- **独立水战规则与独立水战界面**（水路航行已纳入，见 §5.1；两者不是一回事）
- 美术资源铺量；资产只做「城池 / 关隘部件」最小集
- 完整复刻原版彩蛋；情怀项一律走设置开关

**「非目标」不是「以后再说」**。它是「现在说不」，防止排期被悄悄塞满。
真要改，先改这份文档，再改排期 —— 顺序反了就会变成「先做，再找理由」。
