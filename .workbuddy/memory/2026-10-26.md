# 2026-10-26

## 全地图模式升级评估（产出：docs/全地图模式升级评估-v1.md）

- 任务：评估把现有「节点图 + 12×8 独立战棋」升级为《三国志11 威力加强版》式全地图模式的可行性与方案，只评估不实现。
- 基线实测：`src` 24,898 行 / 92 文件，`tests` 6,174 行 / 38 文件 / 334 用例；61 城 + 123 边；城市坐标 x175–935 / y120–675（示意坐标）；战棋 13 文件 3,387 行；`SAVE_VERSION = 3`；无任何 hex/tilemap 基础设施。
- 依赖面：`neighborsOf` 13 源文件、`createBattle` 6 源文件 + 18 测试、`locationId` 48 文件。
- 核心判断：技术可行，但本质是「换战略层引擎」而非加功能；成本集中在状态拓扑（图 → 栅格）与部队级 AI，不在渲染。
- 三档方案：S 档地形化 25–40 人日 / M 档部队上地图 100–150 人日（推荐）/ L 档完整版 150–220 人日。
- 关键硬约束：月回合 + 61 城 + 合理行军速度三者不可同时成立，建议改旬回合（3 回合/月）+ 84×64 中地图。
- 隐蔽技术债：现有 `reduce()` 全量 `structuredClone`，地形必须用 `Uint8Array` 且不进 draft 克隆，否则每次点击掉帧。
- 分阶段方案：阶段 0 规格裁决 → 1 地图地基 → 2 部队与行军（风险最高）→ 3 遭遇与战斗接入 → 4 战略 AI 与平衡 → 5 可选 L 档延伸。每阶段结束均为可玩版本。
