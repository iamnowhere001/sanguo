# 2026-10-29

## 地图引擎与工具选型评估（产出 docs/地图引擎与工具选型评估-v1.md）

- 基线实测：`src` 38,654 行 / 113 文件；`render` 7,357 行；`ui` 7,228 行；`tests` 7,770 行 / 45 文件。地图 576×432 = 248,832 格。
- 关键发现（都已写入文档，后续别重复挖）：
  - 地形分块 = 384 世界单位（32 格）× 1.5 px/单位 = **18 px/格**，LRU 32 块 ≈ 42 MB；720% 时放大 2.2×。
  - `MapCanvas` **无 rAF**；`BattleCanvas` 已有 fx 层 rAF 范式（`BattleCanvas.tsx:1669,1716`，30fps 节流 + reduced-motion）→ 地图层照搬即可。
  - `imageSmoothingEnabled = true` 与「新国风像素」冲突；缩放手感是连续 1.12 倍且锚定选中城池/屏幕中心，非光标；移动端无双指捏合。
  - **无任何版图/每格归属数据**（`territory|influence|tileOwner` 零命中），势力色只有城池径向光晕。
  - `perf:check` 明文不测浏览器 FPS（只测建局/AI月结/存档序列化）→ 无渲染基准。
- 选型结论：**不换引擎**。P0 补地基（渲染基准 / tileOwner 多源 Dijkstra 场 + d3-contour 边界 / 分层+rAF / 相机数学 / Tiled 资产管线）；P1 才考虑 PixiJS 8 只换 render 内核（@pixi/react 8.0.5 停更 2025-12、pixi-viewport 6.0.3 停更 2024-11，手写挂载）；P2 Phaser 4 `TilemapGPULayer` 仅在 P1 证伪后；Godot/Unity/Cocos/LayaAir/three/MapLibre 全部否决。
- 核对过的版本（2026-10-29）：pixi 8.22.0、phaser 4.2.1、three 0.186.1、@babylonjs/core 9.33.0、excalibur 0.32.0(BSD-2)、Godot 4.7.2、Unity 6000.6、Cocos 3.8.8、Tiled 1.12.x(GPL-2.0+ 编辑器 / TMX 规范 BSD)、LDtk 1.5.x(MIT)。

## P0 落地（同日晚）

新增文件：
- `src/systems/territory.ts` — 多源 Dijkstra 版图场（桶队列 + 整图代价 LUT）。稳态重算 12ms，首算 39ms。山地按 12 天/格放宽，其余复用 `marchDaysForArmy`，所以版图边界与部队可走路径同源。
- `src/render/territoryPaint.ts` — 1px/格 铺色 + 放大模糊出墨线，运行时用 `multiply` 保留宣纸明暗；`territoryWash(zoom)` 控制强度（20%→0.87 / 100%→0.55 / ≥200%→0.15）。
- `src/render/camera.ts` — 相机数学外置：`zoomAt` 光标锚点、`ZOOM_STOPS` 15 档吸附、`pinchScale`、`easeCamera`。配 `tests/camera.spec.ts` 9 例。
- `scripts/render-bench.mjs` + `bench.html` + `src/bench/main.tsx` — CDP 驱动无头 Chrome 测端到端 rAF 间隔。
- `tests/territory.spec.ts` 8 例。

MapCanvas 改动要点：
- 地形**渐进烘焙**：`chunkBakeBudget = 6/帧`，缺块先用 `terrainOverview()` 对应区域垫底，90ms 后补烘。这是缩放 150ms 卡顿的真凶。
- 势力光晕改预烘精灵（`glowSprite`），去掉每帧 61 次 `createRadialGradient`。
- wheel 改**函数式 setView**（多个 wheel 事件在一帧内会互相覆盖）。
- 惯性甩动 `startFling`、双指捏合 `pointersRef/pinchRef`、hover 30ms 节流。
- `imageSmoothingEnabled = view.zoom < 2`（像素美术近景关插值）。
