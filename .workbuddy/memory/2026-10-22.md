## 三国霸业 Web 版：右栏（城池面板）信息架构重构

- 目标：首屏即可见核心信息与常用操作，减少滚动；信息分层（主/次/参考）。
- `CityPanel.tsx` 结构改为「常驻头部 + 分区标签 + 滚动区 + 常驻页脚」：
  - 头部：城名/势力/地形 + 四格 KPI（金钱、粮草含进度条、驻军、月净粮）+ 单行派生信息（月产/月耗/季税/训练）。
  - 标签页 `城务|人事`（role=tablist，左右方向键切换）：城务 = 内政 + 征兵 + 交易；人事 = 忠诚/宴请 + 在城武将 + 俘虏。两个 pane 均挂载、用 `hidden` 控制显隐（保留输入状态，也让既有冒烟测试仍能读到文案）。
  - 基础属性（农业/商业/民忠/防灾/训练）降级为一条分隔线横条，不再占 5 张卡片。
  - 首屏告警条（粮草近上限 / 无武将 / 忠诚告警）带「去征兵 / 去宴请」直达按钮，切换分区并 scrollIntoView。
  - 武将行压缩：等级右对齐、兵力条与数字同行、道具与「调往」合并进 `.g-ops` 一行。
- CSS：删除废弃的 `.stat-grid/.stat/.forecast`，新增 `.cp-*` 系列；`.cmd-grid` 改 3 列；`.panel-section` 纵向间距 16→12。
- 验证：`tsc --noEmit`、`vite build`、对比度检查、`ui.smoke` 10 项全过；用 react-dom/server 渲染真实组件 + Chrome headless 在 1440×900 / 1280×800 / 1080×800 三档截图核对（含告警态、人事页、敌方城池）。
- 已知既有失败：`pipeline.spec.ts` 6 项、`difficulty.spec.ts` 1 项，仍为配表并发改动导致，与本次 UI 改动无关。
